# MeetFlow — система обліку зустрічей (Java 21 + JSP + Tomcat + PostgreSQL)

**MeetFlow** — це вебзастосунок для управління робочим розкладом та бронювання зустрічей, написаний на чистій **Java 21** із використанням **Servlet та JSP**, розгорнутий на сервері **Apache Tomcat** із базою даних **PostgreSQL**. Для зручності написання сутностей використовується **Lombok**.

---

## 📌 Основні можливості

* Додавання та управління вільними слотами через вебформи.
* Перегляд доступних для запису часових проміжків на JSP-сторінках.
* Бронювання слотів із збереженням стану в базу даних PostgreSQL.
* Перегляд власних зустрічей у профілі користувача.

---

## 🏗️ Технологічний стек

* **Мова програмування:** Java 21
* **Сервер додатків:** Apache Tomcat 10+
* **Інтерфейс (View):** JSP (JavaServer Pages), HTML/CSS
* **База даних:** PostgreSQL + JDBC
* **Інструменти кодування:** Lombok (генерація конструкторів, геттерів/сеттерів)
* **Система збірки:** Maven
* **Тестування:** JUnit 5 + Mockito

## 🚀 Швидкий старт і розгортання

### Передумови
* **JDK 21**
* **Apache Maven**
* **Apache Tomcat 10+**
* **PostgreSQL** (створена база даних `meetflow_db`)

### 1. Клонування репозиторію
```bash
git clone [https://github.com/your-username/meetflow.git](https://github.com/your-username/meetflow.git)
cd meetflow
2. Налаштування бази даних
Створіть базу даних у PostgreSQL та налаштуйте підключення (параметри у файлі конфігурації або db.properties).

3. Збірка проєкту у .war файл
Bash
mvn clean package
4. Деплой на Apache Tomcat
Скопіюйте згенерований файл target/meetflow.war у директорію webapps вашого сервера Apache Tomcat та запустіть сервер. Застосунок буде доступний за адресою: http://localhost:8080/meetflow/slots

🧪 Запуск тестів (JUnit 5 + Mockito)
Для перевірки бізнес-логіки сервісів за допомогою юніт-тестів виконайте:

Bash
mvn test
